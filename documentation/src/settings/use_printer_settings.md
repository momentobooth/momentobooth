### Use Printer Settings for Native Printers

This setting controls the `usePrinterSettings` property of the [Flutter printing library](https://pub.dev/packages/printing), which lets the printer driver apply its own settings. It applies to all printer nodes with the _Native_ backend on the [Print routing](settings_print_routing.md) page. This setting is Windows only, and makes a difference on some but not all printers, experiment.
