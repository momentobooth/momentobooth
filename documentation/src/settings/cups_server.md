### CUPS URI

The URI of the CUPS server that printer nodes with the _CUPS_ backend print to, e.g. `http://localhost:631/` for a CUPS server on the same computer. The CUPS queues and their media sizes shown on the [Print routing](settings_print_routing.md) page are read from this server.

### Ignore TLS Errors

Whether to ignore TLS errors when connecting to the CUPS server. This is useful for the self-signed certificates that the CUPS service uses by default.

### CUPS Username and Password

The username and password used to log in to the CUPS server, if it requires authentication. Leave them empty otherwise.
