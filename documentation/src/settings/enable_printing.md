### Enable Printing

This setting determines whether users can print photos in this project.

If enabled, the print button is shown on the share and photo detail screens, provided at least one print size is routed to a printer on the [Print routing](settings_print_routing.md) page. If disabled, the print button is hidden, regardless of the print routing.

This setting can also be toggled with the _Printing_ quick action in the settings panel, for example to quickly stop printing when the paper runs out.
